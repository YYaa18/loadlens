# 宣传素材

## 一句话介绍

电脑为什么变慢、风扇为什么响、硬盘被谁占满了？**负载侦探 LoadLens** 用大白话说清楚。

## 三条卖点

1. **菜单栏常驻，点开就懂**：实时 CPU、内存、温度、磁盘，一句话结论 + 能马上做的建议。
2. **硬盘空间看得见**：容量、健康、读写速度、可清理空间；只读统计，不删任何文件。
3. **AI 助手有数据依据**：能自己调用只读工具查进程、内存、磁盘明细，再给出建议；支持 DeepSeek、OpenAI、Claude、Gemini、本地 Ollama 等。

再加一条：**只读、零权限，常驻约 0.3% CPU**，不打扰日常使用。

## 适合谁

- 风扇一响就不知道该怎么办的 Mac 用户
- 硬盘总是满、又不敢乱删文件的人
- 想把「电脑体检」讲给家人朋友听的人
